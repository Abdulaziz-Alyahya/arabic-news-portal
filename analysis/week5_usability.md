# Week 5 Usability Check

I tested the portal with one person without explaining the interface first.

The task was:

“Find one story and compare how different Arabic news sources report it.”

The user was able to understand the main idea of the portal and said that the interface was clear. The user understood that the website is used to compare how different news sources cover the same story.

The user was also able to browse the stories and use the comparison page without needing additional explanation.

No major usability problems were found during this test, so no additional interface changes were necessary.

This was a small usability check with one person and was used to confirm that the main workflow of the portal is understandable.
